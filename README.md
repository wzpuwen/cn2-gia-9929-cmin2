## 三网优化VPS到底优化了什么

优化的是回程路由。国内用户访问海外VPS，流量要经过运营商骨干网出口；普通线路走163骨干网，电信、联通、移动的流量挤同一条管道，晚高峰拥塞、延迟飙到三四百毫秒都是常态。

三网优化的做法是让三家各走各的精品专线：电信用户走CN2 GIA（AS4809，电信自家顶级线路，省级和国际出口全程专线）；联通用户走AS9929（联通精品网，俗称CU2）；移动用户走CMIN2（AS58807，移动国际精品网）。谁都不用去挤163那根老水管。

有个细节容易被忽略：**三网优化不代表三家走一样的线路**。比如搬瓦工与NodeSeek合作的那款美西套餐，实际组合是电信CN2 GIA、联通和移动都走CMIN2——联通用户借道移动的精品网，实测从上海回程延迟会高出几十毫秒，不过测评结论是多数场景感知不到。看套餐页时把三家各自走什么线路看全，比记住“三网优化”四个字重要得多。

另外留意“双程优化”：有的商家只优化回程，去程仍走普通线路；VMRack洛杉矶、NoslaCloud东京这类标明“双程CN2 GIA+9929+CMIN2”的款，去程回程都走精品线，晚高峰表现通常更稳。

## “不限流量”的隐藏规则：流量随便跑，速度有上限

先把结论放这里：目前市面上在售的不限流量套餐，端口带宽都设了上限，商家用限速对冲不限量的成本。判断一台不限流量VPS值不值，先把端口带宽和价格摆出来看。

几个已核验的例子摆在一起就很直观：

- QQG.NET洛杉矶款：100Mbps端口，不限流量，中国直连优化线路，12.99美元/年；

同样标着“不限流量”，100Mbps年付12.99美元和20Mbps月付498元是两类产品：前者拼大流量性价比，后者卖的是IP纯净度。算一笔“每Mbps月成本”就能看出定位差异，这比“每GB成本”更能反映这类套餐的真实价值。

带宽怎么对应用途，给个粗略标尺：20Mbps够SSH和轻量代理；100Mbps覆盖日常下载和多设备；500Mbps以上才谈得上高清串流、多人合用不卡。还有一个小细节：限量套餐要看清流量是单向还是双向计费——Neburst香港款标的就是“500GB单向流量@1Gbps”，只算一个方向。不限流量套餐一般没这个问题，但比价限量款时容易踩。

## 三网优化VPS常见问题

**不限流量VPS能一直满速跑吗？**
速度上限由端口带宽决定。目前各家放出的不限流量套餐端口从20Mbps到200Mbps不等，“不限”指的是流量不计量，速度封顶值写在你买的端口上。

**三网优化和CN2 GIA是一回事吗？**
不是。CN2 GIA只覆盖电信用户，三网优化是三家各走专线。只标CN2 GIA的套餐，联通和移动用户走的线路要看商家另外怎么接——常见的是联通4837、移动CMI直连，也可能退回普通线路。

**美西和香港机房怎么选？**
